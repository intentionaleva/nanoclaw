---
name: nanoveil
description: >-
  Automatically protects every message from leaking PII, credentials, or secrets upstream
  before the LLM or any external system sees them. Redacts emails, phone numbers, names,
  addresses, IBANs, SSNs, credit cards, API keys, tokens, database URLs, and more.
  Also detects prompt injection attempts. Works silently on every message — no commands needed.
